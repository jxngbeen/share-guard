# REDACT 브랜드 자산 — v0.4.5

2026-10-27 기준. 사이트와 확장이 공유하는 브랜드 자산입니다.

REDACT의 굵은 가림 막대, 좌상단·우하단 단차, 둥근 모서리와 원래 워드마크 윤곽을 사용하는 브랜드입니다.

- `mark.svg`: 심볼의 윤곽을 보존한 밝은 벡터 심볼.
- `wordmark.svg`: share-guard 글자 윤곽을 보존한 워드마크. 시스템 폰트로 대체하지 않습니다.
- `icon.svg`, `icon-180.png`: 어두운 둥근 타일에 동일한 심볼을 넣은 사이트 아이콘.
- 확장의 `icons/`에 동일한 심볼·워드마크와 16/32/48/128px 아이콘을 사용합니다.

헤더·히어로·체험 팝업·실제 팝업·툴바·파비콘·터치 아이콘을 같은 원본으로 맞춥니다. 시안 보드의 설명 문구와 개인 작업 파일은 배포에 넣지 않습니다.
