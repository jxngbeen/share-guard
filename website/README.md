# 소개·체험 사이트 — v0.4.5

문서 확인: 2026-10-27. 소개·체험 사이트는 공개 정적 배포이며 다운로드 버튼은 GitHub Release의 검증된0.4.5 ZIP으로 연결합니다. [배포 안내](../DEPLOYMENT.md)를 참고하세요.

Graphite 흑백 화면과 REDACT 심볼을 사용하는 정적 사이트입니다. 소개 → 웹 체험 → 동작 방식 → 정보 처리 → 지원 범위 → 설치 → FAQ → GitHub 아이콘·정책 안내 순서로 구성했습니다.

`npm run site:build`는 이 폴더의 HTML/CSS/JS, `brand/`의 선택한 자산, `extension/detector.js`와 `extension/popup.css`의 원본 복사본을 `dist/site/`에 준비합니다. 설치 ZIP은 명시된 확장 파일 15개만 포함합니다. `dist/`와 ZIP은 Git에 넣지 않습니다. `npm run site:preview`로 로컬에서 열 수 있고, 같은 정적 디렉터리를 일반 정적 호스팅에도 배포할 수 있습니다.

## 체험의 범위

- 일상 글쓰기(전화/이메일), 민감한 번호(주민/계좌/카드), 개발 메모(키/여권)의 **합성 예시**만 제공합니다.
- 확장과 동일한 감지/문맥/가리기 함수를 사용합니다. 선택·선택 해제·삭제·직전 복원 및 원문 행/글자 위치를 제공합니다.
- 입력을 바꾸면 1초 뒤 다시 검사합니다. 검사 대기 중에는 이전 결과와 수정 버튼을 숨기거나 비활성화합니다. 한글 조합 중에는 검사하지 않습니다.
- 직접 입력한 글은 네트워크로 보내거나 localStorage 등에 저장하지 않습니다. DOM/메모리에서만 처리합니다. 외부 CDN, 폰트, 분석 도구, AI API를 호출하지 않습니다.
- 후보 문맥은 `textContent`로 넣어 HTML처럼 보이는 입력도 마크업으로 실행하지 않습니다. 모든 감지 후보 값은 문맥에서 유형명으로 대체합니다.
- 정적 파일을 불러오는 접속 자체는 호스팅 서버와 통신합니다. ‘체험 입력 전송 없음’은 호스팅의 접속 기록 부재를 뜻하지 않습니다.
- 체험은 이 페이지의 연습용 textarea에만 적용합니다. 실제 확장 팝업을 여는 기능이나 모든 사이트 지원을 뜻하지 않습니다. 본문 강조 효과를 실제 확장 기능처럼 표시하지 않습니다.
- 웹 체험의 복원은 직전 수정 한 번이며 사용자가 글을 편집하면 초기화됩니다. 실제 네이버 연동의 문단 단위 복원은 별도 기능입니다.

## 확인한 범위

Chrome에서 합성 예시 3종/7유형, 전체 선택 해제, 개별 전화번호만 삭제, 전체 가리기/정확한 원문 복원, 변경 뒤 커서 위치, 추가 입력 시 복원 해제, 1초 대기 재검사, FAQ 열기를 확인했습니다. 데스크톱과 390px 너비 iframe의 실제 렌더링을 눈으로 확인했습니다. 후속 수정에서는 320·375·768·1024px iframe에서 헤더·체험·푸터·정책 문서의 실제 렌더링을 확인했습니다. iframe 확인은 실제 스마트폰이나 다른 OS 브라우저 검증을 대신하지 않습니다.

확장 규칙 테스트 180개 통과. 사이트의 detector 파일이 원본과 동일하고, 다운로드 ZIP의 15개 파일이 확장 소스와 일치하는지 검사했습니다. 새로운 브랜드 변경으로 확장의 네이버 편집 로직은 바꾸지 않았으며 네이버 재검증을 새로 수행했다고 주장하지 않습니다.

사이트는 소개와 웹 체험으로 구성되며 영상 파일을 포함하지 않습니다.

## 링크와 정책

공식 설치 파일은 GitHub Release에서 제공합니다. 소셜 링크는 일반 링크이며 추적 위젯을 넣지 않습니다. 이용약관과 개인정보 처리방침은 현재 무료·브라우저 내부 처리 기능에 맞춘 초안입니다. 공개 열람에는 로그인하지 않으며 호스팅의 접속 기록은 별도 처리로 구분합니다. 별도 문의 정보 수집 기능은 없습니다. 기능과 운영 방식을 바꾸면 관련 정책도 함께 검토합니다.

푸터는 중앙 GitHub 아이콘과 두 정책 링크만 표시합니다. 소셜 아이콘은 접근 가능한 이름과 44px 클릭 영역을 갖습니다.

## 등장 효과

첫 화면과 스크롤로 들어오는 구간은 한 번씩 부드럽게 나타납니다. 새로고침 시 다시 시작하며 스크롤 위치를 강제로 이동하지 않습니다. IntersectionObserver를 사용하고 외부 애니메이션 라이브러리는 불러오지 않습니다. 키보드 포커스가 들어간 영역은 즉시 표시합니다. 동작 줄이기 설정, API 미지원 또는 초기화 실패 시 모든 내용을 그대로 표시하며, JavaScript 없이도 소개와 정책을 읽을 수 있습니다.

## 팝업 디자인 통일 (0.4.5)

웹 체험과 실제 확장은 동일한 `extension/popup.css`를 사용합니다. 520px 높이에서 헤더·작업 버튼·하단 안내를 유지하며 많은 후보는 목록 내부에서 스크롤합니다. 실제 팝업은 가용 높이가 작으면 뷰포트에 맞게 줄어듭니다. 양쪽의 수정 대상 안내와 하단 보조 기능은 실제 탭/체험이라는 차이에 맞게 표시합니다. 승인한 REDACT 심볼·워드마크와 아이콘을 모두 같은 원본으로 교체했습니다.
