    1. 1

      다운로드한 ZIP의 압축을 풀어요.

      압축을 푼 폴더는 설치 후에도 같은 위치에 보관해 주세요.

    2. 2

      Chrome 확장 관리 화면을 열어요.

      주소창에 chrome://extensions를 입력하고, 오른쪽 위의 개발자 모드를 켜세요.

    3. 3

      압축해제된 확장 프로그램을 로드해요.

      해당 버튼을 누르고 압축을 푼 폴더를 선택하세요. 도구 모음에 아이콘을 고정하고 검사할 사이트의 접근을 허용하면 준비 끝.

    이미 설치했다면 기존 폴더를 새 파일로 업데이트하고 확장 관리 화면에서 새로고침하세요. 작성 중인 글을 보존한 뒤 글쓰기 페이지도 새로고침해 주세요.

    궁금한 점이 있나요?

    웹 체험과 실제 확장은 무엇이 다른가요?

    웹 체험은 이 페이지의 연습용 글만 검사하고 수정해요. 같은 감지 규칙을 사용하지만 실제 확장은 지원하는 사이트의 입력창에서 자동으로 검사하고 Chrome 기본 팝업을 열어요. 사이트마다 감지·수정 지원 범위가 다를 수 있어요.

    내 글을 AI가 읽나요?

    제품 실행에는 AI API를 사용하지 않아요. 글은 브라우저 안에서 규칙으로 검사해요. AI 코딩 도구를 활용해 개발한 프로젝트이며, 개발 도구와 제품의 실행 방식은 별개예요.

    왜 사이트 접근 권한이 필요한가요?

    글을 쓰는 입력창을 읽고 선택한 부분을 수정하려면 사이트 접근이 필요해요. Chrome 설정에서 허용 범위를 제한할 수 있지만, 클릭할 때만 접근하도록 설정하면 상시 검사가 동작하지 않아요. Chrome 내부 화면과 웹 스토어 같은 제한 페이지에서는 작동하지 않아요.

    후보가 잘못 감지되거나 빠질 수도 있나요?

    네. 정해진 형식과 주변 표기를 사용하는 규칙 기반 도구라 오탐과 누락이 있을 수 있어요. 발견한 내용을 확인하고 필요한 항목만 선택해 주세요. 계좌번호 앞의 ‘계좌’ 같은 표기는 판단에 영향을 줘요.

    언제든 수정 내용을 되돌릴 수 있나요?

    직전 수정에 한해 지원해요. 페이지를 새로고침하거나 검사를 끄면 복원 정보가 사라져요. 수정 대상의 글이나 서식이 달라지면 새 내용을 덮어쓰지 않도록 복원을 거절할 수 있어요. 네이버 내부 편집기 변경으로 호환성이 달라질 수도 있어요.

    이미 공유했거나 자동 저장된 내용도 보호하나요?

    게시·전송·자동 저장을 막거나 이미 공유한 내용을 회수하지 않아요. 공유하기 전에 스스로 확인하는 데 도움을 주는 도구예요.
