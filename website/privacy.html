PRIVACY POLICY

개인정보 처리방침

시행일 2026년 10월 25일 · 최종 수정일 2026년 10월 27일

share-guard는 글의 민감정보 후보를 브라우저 안에서 확인합니다. 이 방침은 사이트와 확장에서 직접 처리하는 정보, 호스팅·외부 플랫폼에서 처리하는 정보를 구분해 설명합니다.

1. 적용 범위와 기본 원칙

운영자는 share-guard 개발자입니다. share-guard에는 별도 회원가입·결제·광고 추적·방문자 분석 기능이 없습니다. 확장과 웹 체험이 검사하는 원문, 후보 값, 복원용 원문을 운영자 서버나 외부 AI API로 보내지 않습니다.

사이트 파일을 불러오거나 외부 다운로드 링크를 여는 통신은 아래 별도 항목을 참고해 주세요. ‘검사 원문 전송 없음’이 모든 외부 서비스의 접속 기록까지 없다는 뜻은 아닙니다.

2. 브라우저 안에서 처리하는 정보

검사할 글과 민감정보 후보
목적후보 탐지, 위치·가려진 문맥 표시, 이용자가 선택한 수정.
처리 위치웹 체험 페이지 또는 확장과 현재 문서의 메모리.
보유·해제문서가 닫히거나 새로고침될 때 해제됩니다. 확장의 입력 대상 변경·일시정지에 따라 원문과 검사 상태도 초기화됩니다. 별도 영구 저장소에 저장하지 않습니다.
직전 수정 전 내용
목적직전 가리기·삭제의 복원.
보유·해제복원에 필요한 한 단계만 메모리에 보관합니다. 페이지 새로고침·종료, 확장 일시정지·입력 대상 변경 등으로 해제됩니다. 웹 체험에서는 직접 글을 편집해도 초기화됩니다.
확장의 동작 상태
항목탭·문서·프레임 식별자, 마지막 입력 활동 시각, 후보 수, 탭별 검사 정지 상태. 검사한 원문은 포함하지 않습니다.
목적결과를 해당 탭에 연결하고 검사 정지 상태를 유지.
보유·해제Chrome의 임시 세션 저장소에서 처리합니다. 탭 종료·브라우저 재시작 등으로 정리되며, 페이지 이동 시 해당 문서 연결 정보가 초기화됩니다.

확장이 적용된 원래 웹사이트는 자신의 정책에 따라 글을 저장하거나 전송할 수 있습니다. share-guard는 해당 사이트의 자동 저장·게시 처리를 통제하지 않습니다.

3. 사이트 접속과 호스팅

이 사이트는 OpenAI Sites에서 호스팅됩니다. 공개 사이트는 ChatGPT 로그인 없이 열람할 수 있습니다. 호스팅 제공자는 사이트 제공·보안 등의 목적으로 접속 IP·브라우저 정보·접속 시각·쿠키 등을 처리할 수 있습니다. 제공자의 별도 계정 기능을 이용하면 해당 서비스의 계정 처리 정책이 적용됩니다.

현재 share-guard의 정적 사이트에는 로그인 계정 정보나 접속 기록을 별도 데이터베이스에 수집·저장하는 코드가 없습니다. 호스팅 제공자의 처리 항목·보유 기간·국외 처리·권리 행사 방법은 OpenAI 개인정보 처리방침을 확인해 주세요.

4. 별도 정보 수집 기능

현재 사이트에는 문의 폼이나 고객 지원용 개인정보 입력 기능이 없습니다. 별도 문의 계정 정보나 메시지를 수집하는 기능도 제공하지 않습니다. 추후 정보 수집 기능을 추가하면 처리 항목·목적·보유 기간과 권리 행사 방법을 먼저 안내합니다.

5. 제공·위탁·외부 링크와 쿠키

검사 원문과 후보 값을 판매하거나 광고·AI 학습 목적으로 제공하지 않습니다. 해당 원문의 서버 처리나 외부 AI 분석을 위탁하지 않습니다. 사이트 호스팅에 관한 처리는 3항에서 구분해 안내합니다.

GitHub 링크와 확장 다운로드 버튼은 GitHub 저장소·Release 자산으로 이동하는 일반 링크이며 소셜 피드나 추적 위젯을 삽입하지 않습니다. 링크를 열면 해당 서비스가 접속 정보를 처리할 수 있습니다. share-guard 앱 코드가 별도로 설정하는 추적 쿠키는 없습니다. 호스팅 제공자나 외부 서비스의 쿠키는 브라우저에서 관리할 수 있습니다.

6. 이용자의 선택과 권리

확장의 사이트 접근 범위를 Chrome에서 제한하거나 탭 검사를 끄고 확장을 삭제할 수 있습니다. 웹 체험은 글을 지우거나 페이지를 닫아 종료할 수 있습니다. 원래 웹사이트에 저장된 글은 해당 사이트에서 별도로 관리해 주세요.

로컬에서만 처리되어 운영자가 보유하지 않은 검사 원문은 운영자가 조회하거나 대신 복구할 수 없습니다. 호스팅 제공자가 처리하는 계정·접속 정보의 열람·정정·삭제·처리 정지는 해당 제공자의 권리 행사 창구에서 요청할 수 있습니다.

개인정보 침해 상담이나 신고 안내는 개인정보 포털에서 확인할 수 있습니다.

7. 보호 조치

검사 원문을 전송하지 않고 메모리에만 유지하며, 후보 문맥을 표시할 때 값은 유형명으로 가립니다. 웹 체험의 입력은 HTML이 아닌 텍스트로 표시합니다. 확장은 필요한 사이트 권한 안에서 동작하고, 웹페이지와 확장의 메시지 경계를 검사합니다.

이 조치가 모든 유출을 막는다는 뜻은 아닙니다. 웹 체험에는 가상 예시를 사용하고 공유 전 내용을 직접 확인해 주세요.

8. 방침 변경과 프로젝트 안내

기능이나 처리 방식이 바뀌면 이 페이지의 내용과 수정일을 갱신합니다. 수집 항목이나 처리 목적 등에 중요한 변경이 있으면 사이트에 안내하고, 법령상 필요한 절차를 거쳐 적용합니다.

프로젝트 안내는 GitHub 저장소에서 제공합니다.
