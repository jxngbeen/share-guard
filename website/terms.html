이용약관

시행일 2026년 10월 25일 · 최종 수정일 2026년 10월 27일

share-guard를 사용하기 전에 서비스의 역할과 한계를 확인해 주세요. 이 약관은 소개·체험 사이트와 Chrome 확장 프로그램에 적용됩니다.

1. 서비스와 운영자

share-guard는 글에서 민감정보 후보를 찾고, 이용자가 선택한 항목을 가리거나 삭제하도록 돕는 무료 도구입니다. 운영자는 share-guard 개발자입니다. 프로젝트 안내는 GitHub 저장소에서 제공합니다.

현재 유료 결제나 구독을 제공하지 않습니다. 사이트는 로그인 없이 공개 열람할 수 있으며, 별도의 share-guard 회원 계정은 만들지 않습니다.

2. 제공하는 기능과 한계

확장 프로그램은 지원하는 입력창에서 정해진 규칙으로 민감정보 후보를 검사합니다. 웹 체험은 이 사이트의 연습용 입력창에만 적용됩니다. 설치 및 지원 범위는 설치 안내와 사이트의 지원 표를 확인해 주세요.

  • 오탐과 누락이 있을 수 있으며, 후보가 없다는 결과가 안전을 보장하지 않습니다.
  • 게시·전송·원래 사이트의 자동 저장을 차단하거나 이미 공유된 정보를 회수하지 않습니다.
  • 실제 번호의 발급 여부, 계좌의 존재, API 키의 유효성은 확인하지 않습니다.
  • 브라우저나 사이트의 변경으로 감지·수정·복원이 제한될 수 있습니다. 복원은 직전 수정과 지원 조건에 한정됩니다.

3. 이용 시 지켜야 할 사항

본인이 작성하거나 적법하게 처리할 수 있는 내용에 사용해 주세요. 타인의 권리를 침해하거나 법령을 위반하는 목적으로 이용해서는 안 됩니다. 체험에는 제공된 가상 예시를 사용하고, 실제 주민번호·비밀번호·인증키 등을 넣지 마세요.

변경할 항목을 직접 확인하고 중요한 원문은 별도로 보존해 주세요. 사이트 접근 권한은 필요한 범위에서 설정할 수 있습니다.

4. 콘텐츠와 권리

이용자가 작성한 글의 권리는 이용자 또는 정당한 권리자에게 있습니다. share-guard는 검사나 수정을 이유로 해당 글의 권리를 취득하지 않습니다. 서비스 명칭·디자인·코드의 권리는 각 권리자에게 있으며, 소스 코드에 별도 라이선스가 표시된 경우 해당 조건을 따릅니다.

5. 변경과 제공 중단

오류 수정, 보안 개선, 브라우저 호환성 또는 운영 사정에 따라 기능을 변경하거나 제공을 중단할 수 있습니다. 이용에 중요한 변경은 사이트에서 알립니다. 별도로 내려받은 확장의 업데이트는 이용자가 설치 안내에 따라 적용해야 합니다.

6. 책임과 이용자 권리

운영자는 오류와 보안 문제를 확인하면 합리적인 범위에서 개선합니다. 서비스 결과의 완전성이나 지속적인 가용성을 보장하지 않으며, 이용자는 공유할 내용을 최종 확인해야 합니다.

이 약관은 관계 법령에서 보장하는 이용자의 권리 또는 법령상 제한할 수 없는 운영자의 책임을 배제하지 않습니다.

7. 개인정보와 외부 서비스

정보 처리 방식은 개인정보 처리방침에 설명합니다. GitHub 등 외부 링크를 이용할 때는 해당 서비스의 약관과 처리방침도 적용됩니다.

8. 약관 변경과 안내

약관을 변경하면 시행일과 수정일을 갱신하고 중요한 변경을 사이트에 안내합니다. 변경에 동의하지 않으면 사이트 이용을 중단하거나 확장을 삭제할 수 있습니다. 프로젝트 변경 사항은 사이트와 GitHub 저장소에서 안내합니다.
